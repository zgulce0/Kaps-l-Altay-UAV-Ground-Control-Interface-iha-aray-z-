# 🚁 Kapsül Altay – UAV Ground Control Interface (İHA Arayüzü)

> A PyQt5-based UAV Ground Control Interface that retrieves real-time telemetry data via Mission Planner.

## 🇬🇧 English
Kapsül Altay is a UAV Ground Control Interface developed using Python and PyQt5.  
It connects to Mission Planner via MAVLink to retrieve real-time telemetry data and display flight instruments.

### Features
- Real-time telemetry data from Mission Planner
- MAVLink-based UAV connection
- Flight instruments (attitude, altitude, speed, heading)
- Battery and basic flight data monitoring

### Planned Features
- Advanced telemetry graphs

---

## 🇹🇷 Türkçe
Kapsül Altay, Python ve PyQt5 kullanılarak geliştirilmiş bir İHA Yer Kontrol Arayüzüdür.  
Mission Planner ile bağlantı kurarak gerçek zamanlı telemetri verilerini alır.

### Özellikler
- Mission Planner üzerinden canlı telemetri verisi alma
- MAVLink tabanlı İHA bağlantısı
- Uçuş göstergeleri (yapay ufuk, irtifa, hız, yön)
- Temel uçuş ve batarya verileri takibi

### Planlanan Özellikler
- Gelişmiş telemetri grafikleri
